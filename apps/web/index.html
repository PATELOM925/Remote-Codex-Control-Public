Quick Web Setup

Install RCC, generate the token, start the Mac daemon.

The relay token is not inside the website. Your Mac creates it locally, saves it under .dist/backups/, and can copy it to your clipboard.

  1. On the Mac: git clone https://github.com/PATELOM925/Remote-Codex-Control-Public.git && cd Remote-Codex-Control-Public && npm install
  2. Add your Telegram bot token and operator chat id to setup.md.
  3. Generate relay tokens and apply Mac settings: ./scripts/setup_relay_quickstart.sh --configure-vercel --deploy
  4. Run the Runtime smoke check before demoing phone access: set RCC_RELAY_OPERATOR_TOKEN in your shell, then run npm run smoke:runtime
  5. Start RCC: ./run.sh
  6. On your phone: open rcc-magnus-alpha.vercel.app/?mode=relay, leave base URL blank, and paste the copied operator token.

Remote Relay

  • Best for phone/bus access
  • Mac polls outbound, so no public Mac port
  • Queue run, say, interrupt, approve, deny, and small selected-thread file uploads
  • Open a thread for explicit live detail

Local API

  • Fastest if browser reaches the Mac daemon
  • Direct run, steer, interrupt, approvals
  • Explicit local artifact download
  • Uses your private RCC web token

Safety model

  • Same local Codex account
  • No Codex OAuth inside this website
  • No full-disk browser
  • No cloud Codex execution

Quick Web Setup

One Mac command, then connect from phone.

  1. Install from GitHub: git clone https://github.com/PATELOM925/Remote-Codex-Control-Public.git && cd Remote-Codex-Control-Public && npm install
  2. Add your Telegram values to setup.md.
  3. Run ./scripts/setup_relay_quickstart.sh --configure-vercel --deploy.
  4. Run the Runtime smoke check: set RCC_RELAY_OPERATOR_TOKEN in your shell, then run npm run smoke:runtime.
  5. Start the Mac daemon with ./run.sh and keep the Mac awake.
  6. Open this hosted page on your phone, choose Remote Relay, leave base URL blank, and paste the generated operator token.
